# VortexAntep — ortak sanat

Bu işletmenin **tüm** arenalarının (ve lobisinin) paylaştığı malzeme/doku/mesh buraya girer.

Yalnız tek bir arenada kullanılan sanat buraya DEĞİL, o arenanın kendi kutusuna girer
(`Default/Art/` gibi). Ölçüt tek soru: *"bu işletmedeki ikinci bir sahne de bunu aynen kullanır
mı?"* — evet ise burası, hayır ise arena kutusu.
