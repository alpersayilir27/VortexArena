# VortexAntep — ortak prefablar

Bu işletmenin **tüm** arenalarının (ve lobisinin) paylaştığı prefablar buraya girer
(işletmeye özel dekor, tabela, mobilya…).

Tek bir arenaya ait prefab buraya DEĞİL, o arenanın kendi kutusuna girer.

⚠️ Projenin **her** arenasının paylaştığı altyapı prefabları (`VA_CameraRig`, `VA_PoseSync`,
`VA_CalibrationManager`, `VA_ModeHud`) buraya kopyalanmaz — onların tek adresi
`Assets/_Shared/App/Prefabs/`'tır ve sahneye oradan **örnek** olarak konur.
